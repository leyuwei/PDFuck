# 中英文常青宣传物料更新方案

## 制作前规划
- 中文与英文各交付一个 MP4、一个完整 GIF、一个低于 2,000,000 字节的轻量 GIF。
- 保留 60 秒、12 幕、相同功能顺序、配色、镜头与配乐。英文使用真实英文 UI 和英文固定示例回复。
- 所有发布画面、封面、字幕、配文与文件名不写版本号。录制时仅隐藏关于入口的版本标签，不修改应用源码。
- 用 zh / en 区分文件，README 现有图片指向中文轻量 GIF，避免无关改动。
- 先重新采集中英文画面，分别检查预览和英文排版，再编码与验收；新文件验证成功后移除旧带版本号交付文件。
- 制作规范记录语言参数、稳定命名、压缩与验证命令，未来无需因软件版本变化重命名物料。内部溯源记录可以保存实际采集构建版本。

## 验收
- 两套视频尺寸、帧率、时长一致，完整解码通过。
- 四个 GIF 全帧读取通过，循环正常；两份 small.gif 均小于十进制 2 MB。
- 检查英文换行、文字宽度、重点 UI 区域与所有镜头的版本标签隐藏状态。
- 发布文件总计 2 MP4 + 4 GIF，附双语封面与字幕。
