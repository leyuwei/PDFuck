# 2.1.18 计划与范围

> 首轮历史记录；当前同版本已重做为示例文档教学，见 `PLAN-2.1.18-practice.md` 与 `VALIDATION-2.1.18-practice.md`。以下测试未在本次重做中重跑。

1. 首次启动及版本变更时显示五步视觉引导，支持跳过、前后翻页、Esc 和左下角重看。指示左侧模块、书签、批注编辑与快捷处理状态、实验室模型配置、字数和按需资源；无文档时仍可阅读引导。版本完成标记保存在现有用户配置中。
2. 查看、编辑、批注、保存共用标题右侧无边框主题色收起按钮，保持导航图标可展开。
3. PDF 底栏独立显示选区字数，沿用已有汉字/假名逐字、其他语言分词统计，保留选中文字预览。
4. 资源固定在 appData/PDFuck-resources，独立于应用安装目录、版本号及 Electron 配置目录。首次迁移旧 userData/feature-resources，不覆盖新资源、不删除旧数据；代理加密配置仍在原用户配置路径。带显式 user-data-dir 的隔离启动仍保持隔离。依赖清单未变时不重新下载；真实资源版本变化或损坏仍按原校验流程下载。

涉及 renderer App、ToolPanel、新引导组件、十语言目录、main 资源入口和迁移、版本文件及新增测试。不改 README，不新增生产依赖，不改文档内容。

仅执行本次新增单元/UI/包检查、typecheck、直接 electron-vite build，禁止 npm run build 和一键全量打包脚本。当前主机打包 macOS arm64 APP/DMG/ZIP；Windows 路径策略覆盖单元，Windows 实机安装不冒充验证。
