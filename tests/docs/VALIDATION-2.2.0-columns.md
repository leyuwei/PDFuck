# 2.2.0 自动分栏验收

## 根因和修订

原件第 2、5、8 页自动边界为空。它们的局部图框与页眉、页脚横线的左右端点相近，旧分栏代码据此合并出纵向约 721 PDF 点的有线区域，将大部分正文中的栏缝候选挡掉。

修订后，以实际相连的上下边和竖边确定闭合范围，图框边缘不参与独立横线的组合。图内文字仅从栏缝证据中排除，词框和公式识别仍使用全部原始行。分栏证据使用 Unicode 文字、相近字级和重复正文行，排除原件中较小的脚注产生的附加栏缝。真实三栏和边栏仍可识别。自动边界编辑、布局排序与正文拖选沿用同一个检测结果。

## 检查结果

- 本轮新增 15 项单元检查通过，包括十种语言的正文、独立画出的四边图框、装饰框内正文、真三栏、闭合和三线表格，以及手动分栏覆盖。
- 原件和上一轮的脱密副本共 18 页源码窗口检查通过。原件第 2、5、8 页的分隔位置分别为 234.343、338.750、234.331 PDF 点，均位于两栏正文之间。
- 原件和脱密副本共 24 次跨两行的同栏拖选通过，覆盖左栏、右栏和正反向。12 次其他缩放导线检查、两次手动调整和恢复自动、十种界面语言检查通过。一键图表在两个文件中均返回 6 张图。
- 仅运行本轮新增的 `release-2.2.0-columns.test.ts` 和 `release-2.2.0-columns-ui.cjs`，以及类型检查、生产构建和静态打包校验。原件与 README 的 SHA-256 保持一致。
- 保持版本 2.2.0。macOS arm64 安装包采用临时签名，按成品签名、包内文件和校验和验证。成品未启动。
