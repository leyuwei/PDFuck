# PDF 2.2.0 缺字修订

1. 对照原件的参考画布、PDF.js 画布、字形绘制指令和文本提取结果，确认汉字、数字和拉丁字母缺失的路径。
2. 只给有可用 Unicode 映射的缺失字形补绘。使用系统字形并保留 PDF 的绘制位置、字符步进、文字颜色与可见性。查看、预览和栅格输出共用该逻辑，绘制不依赖界面语言。
3. 生成脱密版式副本，并用全新字体子集构造可复现的多语言回归 PDF。核对原件的实际字形、脱密 PDF、正常字形和无可靠映射的字符，以及十种界面语言。
4. 仅运行本轮新增专项，执行类型检查和生产构建，再重打包 macOS arm64 版。保留 README 和版本 2.2.0。成品只核验签名、内容和校验和。
