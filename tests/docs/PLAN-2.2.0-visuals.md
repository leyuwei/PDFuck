1. 逐页对照原件的可见图框、PDF 绘制操作、标题候选和正文词框。记录漏检与误检的基线，并记录相关历史测试原有的失败或缺档。

5. 核对 README 与原件摘要后，沿用 2.2.0 发布线，重建 macOS arm64 包。成品只做签名、包内容与校验和的静态检查。
