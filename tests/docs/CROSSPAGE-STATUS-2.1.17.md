# 跨页选择、文字样式和页码提示验收

本轮仅修改以下五项，保留此前阅读工具、图表隔离、打印、按需资源与编辑功能；根目录 README 未作本轮修改。沿用当前 2.1.17 版本重新打包。

- 多栏跨页框选：在既有 30 页脱敏档案第 12–13 页复现。第 13 页有通栏图，续选原来会通过含页眉的几何带重建范围，额外带入右栏 4 个片段。跨页现在使用已有阅读顺序与字形边界，单页仍使用原有几何重建。排除图、表、单元格及跨页重复的页眉页脚，保留此前通栏公式隔离；正向、反向及部分字符使用同一条路径。
- 添加文字：确认添加时保存字体、字号、颜色、粗体、斜体、对齐和行距。只存本机样式，不存输入文字、PDF 源字体或对象参数。取消不提交；编辑已有对象保留对象原样式，不覆盖新建默认值；损坏或不可用的存储不妨碍添加。
- 批注列表：改为左侧 52 px 元信息与弹性内容两列，删除排版文件中旧的五列覆盖。三个状态按钮只在左侧图标/页码区域悬浮、键盘聚焦或触控打开时浮现。操作面板不改变条目尺寸；移开、失焦或 Esc 收起；保留状态取消、统计、选择、编辑和闪烁定位。
- 背景大页码：纸张后方的加粗低对比度主题色数字，随纸张滚动，窄栏裁切装饰层而不新增横向滚动。装饰层不接收指针、不参与文字复制、不进入 PDF 内容，打印样式隐藏。支持虚拟分页与单页模式。
- 快速滚动页码：快速滚轮或原生滚动条拖动时，在现有顶部提示栈的下一行出现半透明主题色区域；**只显示当前页码数字**。随当前页更新，停止约 0.85 秒后淡出；恢复文档和程序跳转期间不误触发，切换文档/卸载清理监听和定时器。临时文件提示位于阅读区外，返回按钮与分析提示在上一行，避免互相覆盖。

没有新增依赖。已有十语言状态文案直接复用；两个页码装饰均只含数字。
