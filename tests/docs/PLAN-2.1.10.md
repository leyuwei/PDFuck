# 2.1.10 实施与验收计划

## 需求与根因

用户要求修复 `785904351dabdab98176b914912cc8dd.pdf` 两页的自动分栏，将测试及其依赖统一到根目录 `tests/`，不添加或修改 gitignore，同步说明文档，只运行本轮新增测试后打包。

实际渲染确认两页都是双栏，栏沟约为 300.03–311.98pt。原算法以全页视觉基线数的 20% 要求同一行同时出现两栏文字；公式上下标与分式产生额外基线，两栏正文、公式又经常错行。第 1 页得到 71 行、12 次支持（要求 15）；第 2 页 75 行、14 次支持（要求 15），在几何栏沟正确且穿越率很低时仍被丢弃。

## 修改设计

1. 在共享 `textItemsToWordBoxes` 修复几何证据的统计：保留窄栏沟、多行共同走廊，补充邻近但不共基线的两侧行证据。继续排除普通词间距、缩进公式/矩阵，以及缺少持续文字的空白区；不为特定文件或中央 x 坐标加特例。
2. 维持自动检测、手工边界、栏线、选区与页面文字编辑使用同一边界。算法只依赖 PDF 几何，独立于界面语言、主题、界面字号；覆盖中英及 RTL 文本、双栏/三栏、窄栏沟、缩放、跨栏内容和手动清空/覆盖。
3. `tests/unit/` 镜像原 `src/` 目录，迁移全部单元/组件测试并修正 import/mock 路径；`tests/scripts/` 放测试运行器、审计与 UI/成品检查；`tests/fixtures/` 放可复用输入；`tests/docs/` 放版本计划/验证；现有运行缓存和输出分别保留到 `tests/tmp/`、`tests/output/`。生产构建/图标脚本留在 `scripts/`。
4. 更新 package 命令、TypeScript/Vitest 配置、发布脚本和中英文 README/打包指南。不新增依赖，不改 `.gitignore`，检查迁移后的脚本语法、静态路径及样本完整性，不执行历史用例。

## 本轮新增验收与交付

- 新增定向测试：真实两页及错行、密集公式、跨栏内容、单栏/矩阵误报、多栏/窄沟、语言和缩放、手工覆盖；新增迁移结构/路径检查。
- `npm run typecheck`、`npm run test:release-2.1.10`、直接生产构建；新增 Electron 冒烟检查实际两页栏线、双向跨行选区与复制，抽查十语言/双主题/四字号。
- 直接 electron-builder 生成 Windows x64 解包程序、安装器和便携版；对成品执行本轮新增冒烟，逐字节核对生产资源、OCR/原生打印资源、2.1.10 版本、签名状态及 SHA-256。
- 不运行历史测试全集或会触发全集的一键发布命令；不宣称在 Windows 上完成 macOS 构建/安装器实机更新验收。最终结果记录在 `tests/docs/VALIDATION-2.1.10.md`。
