# 2.0.26 实施计划

1. 修正字号通用样式影响原生窗口控制区的高度问题，最小化/最大化/关闭按钮铺满标题栏，悬停背景不留上下空隙。
2. 保持三种字号角色，新增较小预设 10/12/16px；保留标准、较大、最大及已有用户设置。查看的字号按钮右侧显示当前设置，预览、取消与确认同步更新。
3. 文档标签、PDF 徽标、计数徽标整体自适应：文字居中，外框保留上下内边距，多位计数正常容纳，长文件名仍省略显示。
4. 十种语言同步移除编辑模块四个入口的尾部省略号；统一增加左侧工具按钮内边距、按钮间距和分组留白。
5. 扩展现有字号回归，覆盖四档设置、多语言、按钮当前值、窗口控制区、标签及计数居中与边界、工具按钮间距；更新 VI、构建并验证 2.0.26 Windows 成品。
