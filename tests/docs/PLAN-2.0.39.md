# PDFuck 2.0.39 实施计划

本次仅新增“在页面上添加水印”，沿用现有编辑工具、PDFuck 自有注释标记、撤销和保存流程，不增加依赖。

## 范围

- 编辑模块新增同风格水印按钮和矢量图标。
- 水印浮窗支持页码范围、文字、字体、字号、旋转、颜色、透明度和密度，并实时预览。
- 已有水印可整体更新或一键删除；保存并重开后仍可识别。
- 水印在编辑器与最终 PDF 中都严格裁切到页面边界。
- 新增界面文案覆盖现有十种语言。
- 按用户最终确认将发布版本设为 `2.0.39`。

## 验证

- 新增水印平铺与 PDF 写回单元测试。
- 新增轻量 Electron UI 冒烟测试，覆盖入口、实时预览、属性设置、页边界裁切、添加和删除。
- 按用户要求仅运行本次新增测试；生产构建后在 Windows 成品上复跑水印 UI 测试。
- 生成安装版、便携版、SHA-256 与精简验收记录。
