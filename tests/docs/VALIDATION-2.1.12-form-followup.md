# 表单交互与临时标签补充验收

日期：2026-10-30（Asia/Shanghai）。交付版本仍为 2.1.12。

## 交付行为

- PDF.js 原生文字字段接入交互层：查看时可选择复制，编辑模块可直接填写；支持多行、分格、最大长度、隐藏字段、旋转和同名字段同步。原始只读及密码字段不解锁。
- 编辑写入最新 PDF 的原字段 `/V` 和 `/AP`，保留可继续填写的表单结构。缺少中文字形时复用已有文字排版服务嵌入字段外观字体；原外观缺失时显式补齐标准字体资源，避免其他阅读器依赖隐式回退。字段外观与软件接管的页面覆盖层分别过滤，不重复绘制。
- 字段输入立即反映未保存状态；失焦应用。快速连续填写不重建相邻输入框，缩放只调整现有层尺寸。保存、切换、关闭前等待提交，失败保留草稿并阻止保存旧值；Escape 可取消当前字段修改。提交纳入撤销重做；历史检查在操作队列内进行，避免首次提交尚未完成时撤销失效。
- 原生窗口关闭由页面先检查未提交字段，即使窗口此前被视为未修改也不会绕过提交。另存、单标签关闭和多标签窗口关闭共用提交保护。
- 临时文件标签增加琥珀色文件时钟图标，提供悬停说明与无障碍名称。关闭横幅后图标仍保留，另存到正常目录后消失；适配深色及窄标签，并保留未保存点与关闭按钮。
- 根 README 只更新能力和使用说明，不记录版本迭代。未添加依赖；`node_modules/`、临时测试目录、输出和交付目录已被现有 `.gitignore` 覆盖。
