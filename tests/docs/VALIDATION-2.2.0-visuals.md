# 2.2.0 图表识别与框选验收

## 复现和修复

原件共九页。第 2、4、5、6、7、8 页各有一张图。旧版漏检第 2、5、8 页，第 3 页无图却报出整块正文；其余三张图与版面底板合并，范围也扩展到了正文。合并后有的框高达 706 PDF 点，占页高约 92%。旧版还把包围框和粗粒度标题块用于全文选区，容易把相邻正文误归到图表范围中。

现在绘制对象聚合前检查实际透明度和连续正文证据，保留图框、图内绘制和表格线。标题按局部几何、基线及同源文字重组，表注按表格横向范围和字级认定。页面装饰用的外框与实际参与选区的区域独立计算。正文拖选在图内或单元格附近仍以正文为焦点，已有图表内拖选和单元格归属继续可用。一键列表与页面使用同一份识别结果。图题、表题规则覆盖十种界面语言对应的文档标记。

## 本轮检查

- 新增 24 项单元测试，覆盖图文背景、透明绘制、本地标题片段、表注与正文、正文焦点和多语言编号。
- 源码窗口读取原件和脱密副本共 18 页，各识别 6 张图和 3 页无图。逐一核对图框、完整图题、列表跳转和两方向拖选。在两个文档中共执行 36 次正文拖选、24 次图题拖选、8 次图内内容拖选。另用合成西语表格在日语界面验证识别、相邻单元格隔离和下方正文选择。
- 重跑相关的历史单元与脚本。30 页开口表格专项通过 360 组检查，包含跨缩放、字形模式、输入顺序和多行表注。另通过 228 个跨页正文范围、1,113 个正文范围和 30 个历史图题范围，以及两份既有图注夹具的 16 次源码窗口拖选。
- 历史单元为 413 项通过、24 项仍失败，改动前为 411 项通过、26 项失败。历史脚本共执行 61 项，12 项通过、35 项失败、4 项缺夹具、10 项超时。未通过的脚本与改动前源码基线复核，全部在基线也未通过。各脚本的结果和基线日志单独保留，旧套件仍有覆盖缺口。
- `npm run typecheck`、`node_modules/.bin/electron-vite build`、`git diff --check` 与原件、README 摘要核对均通过。

源码测试使用 `tests/scripts/release-2.2.0-visuals-ui.cjs`。带原件路径时会逐页对照两个版本，直接运行时使用脱密副本和合成表格。详细汇总在发布清单，历史比较报告在 `tests/output/release-2.2.0-visuals/`。

## 脱密与交付

9 页脱密副本位于 `tests/fixtures`，版面、图框、文字位置保留，图画以合成矢量占位替代，正文与图内标签全部重排为合成字符。格式审计确认无原件图像、超链接、批注、元数据或嵌入附件，校验 880 条较长原始文本未出现在副本中。版本保持 2.2.0，macOS arm64 成品只用于签名、包内容和 SHA-256 静态核验。没有启动打包后的 APP。
