# 2.0.34 升级计划

1. 打印：拆除打印窗口外层的通用滚动正文，让左侧设置独立滚动；右侧预览占满可用半区并保持纸张比例，底部操作始终可达。
2. 实验室：模型设置仅保留关闭；共用浮窗支持默认右下角定位，内容和窗口尺寸变化时保持可见，用户拖动后保留其位置。画板同样默认右下角；嵌入批注编辑器的建议继续原位显示。
3. 标签档案：点击“文档标签”打开下方浮窗，本地持久保存多个命名文件列表，支持改名、删除和一键补开。保留现有标签与未保存编辑；尚未落盘的文档须先保存。恢复逐个处理，集中报告缺失/打不开/取消的文件，复用现有密码与阅读位置流程。
4. 验证与交付：覆盖存储校验、档案增改删/重启/部分恢复/重复标签、打印滚动与缩放、实验室定位和去最小化；检查十语言、四字号、深浅主题与 RTL。运行构建和改动相关源码/成品检查，跳过无关 OCR、框选大回归。同步版本与文档，生成 Windows 安装版/便携版并核验。
