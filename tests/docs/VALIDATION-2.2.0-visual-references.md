# 2.2.0 关联图表验收

阅读工具中的「关联图表」按文档保存开关。正文中的图表编号与一键图表的已识别区域匹配，图和表分别编号，支持罗马数字、全角和阿拉伯数字以及子图后缀。重复编号优先选择本页的唯一匹配，其它跨页歧义保留为普通正文。图题本身仍可直接框选。

「图表预览」使用原始 PDF 区域绘制，图表和对应正文采用同一个缩放比例。超过浮窗视口的画面可上下或左右滚动，标题栏和跳转按钮留在浮窗边缘。点击「跳转到图表」对齐并高亮正文区域。

只运行本轮新增的 15 项单元测试和源码界面专项。单元覆盖十种语言、编号和标点变体、重号、跨栏误匹配、图题排除与文字框位置。源码窗口检查图和表的预览像素、100%、150%、300% 尺寸、浮窗内滚轮缩放、两次跨页跳转、正文拖选、键盘操作、中文和暗色主题及开关保存。

随后完成类型检查、生产构建和 macOS arm64 2.2.0 打包。README 无改动。发布包采用 ad-hoc 签名，仅执行静态校验。
