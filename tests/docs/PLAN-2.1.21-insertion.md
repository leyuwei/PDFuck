# 插入标记定位与自适应高度补修

按用户确认的三个示例，竖线位于当前行字符间隙，向行内延伸，按正文基线定位，竖线取字框高度约 55%，三角下缘仅略过基线；三角紧接行下方。最近字符边界携带文字高度，直接点击、右键、选区快捷工具和自动批注复用。预览、显示与 PDF 外观共用几何；新标记保存对齐标识，避免重开后重复上移。旧版标记按原锚点和附近文字高度修正屏幕显示。

沿用十语言文案，README、版本 2.1.21、package/lock 不变。只运行新增字符/大小/保存/改色/重开及实际窗口专项、类型检查、直接构建，最后重打 macOS arm64 APP/DMG/ZIP 并执行新增静态包核验。

旧版自建标记在当前文档保存/导出/打印前按真实文字布局更新 PDF 矩形和外观；通过副本完成序列化后才更新模型，保留撤销。外部阅读器的原生 Caret 保持其已有定位语义。
