# On-demand OCR and grammar resources plan

1. Remove release-specific narrative from README. Keep durable feature descriptions and open-source credits in Chinese and English.
2. Pin official OCR runtime packages, individual language models, LanguageTool and platform-specific Java archives with byte sizes and cryptographic digests. Keep manifests and notices in the small app; exclude runtime libraries, models and grammar payloads from builds.
3. Store verified resources and resumable partial archives under the app's user data directory. Validate HTTP ranges, server validators, length and digest; fall back safely when Range is ignored. Use staging and atomic installation so interrupted extraction cannot activate incomplete code. Keep completed downloads across upgrades and interruptions.
4. Use a dedicated Electron network session for system/direct/manual HTTP(S)/SOCKS proxy configuration. Encrypt stored proxy credentials using OS-backed safeStorage. Bound redirects, stalls and retry behavior; never send proxy credentials to origin servers or expose them in progress/errors.
5. Add a localized, draggable resource dialog with size/source disclosure, progress/speed, pause/resume/retry, cancellation and proxy settings. Closing cancels the pending feature operation while preserving partial data. Closing a window or exiting aborts requests without deleting resumable data. Queue independent windows safely and avoid duplicate writes.
6. Preflight OCR/grammar at the feature call sites. Keep document data local; missing resources must never silently disable work or report no issues. Existing PDF behavior remains unchanged.
7. Add only new focused tests: Range/If-Range, ignored/malformed ranges, corruption, network interruption, disk errors, pause/cancel/restart/exit, installation recovery, queue/ownership, proxy/auth isolation, ten-language UI, real downloaded OCR/grammar execution and offline reuse. Use synthetic/public data only.
8. Typecheck, production build and repackage the current version. Static checks must prove heavyweight payloads are absent, licenses/manifests present, code matches, signatures and DMG/ZIP valid. Do not run packaged products, per the user's standing instruction.
