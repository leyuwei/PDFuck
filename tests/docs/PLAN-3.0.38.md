# 3.0.38 升级计划

## 目标

- 修正文本翻译设置窗底部操作区间距。
- 重新组织翻译结果窗的原文、译文和操作区，使信息层级在明暗主题下清晰可辨。
- 降低 PDF 内置链接与关联引文悬停遮罩，保证原文字形持续可读。
- 将文档档案的改名、删除操作移到条目标题右侧，并保持十语言、RTL、大字号和小窗口可用。

## 实现与验收

1. 复用现有弹窗结构，仅调整语义 class 与 CSS；设置窗按钮到分隔线保持至少 14px，结果窗两段内容使用不同底色、边框和至少 12px 间距。
2. 内置链接和引文链接覆盖按钮在普通、悬停、焦点及激活状态下的背景 alpha 均为 0，移除原生 `title`，以多语言 `aria-label`、描边和下划线承担可访问名称与交互提示；测试必须确认元素真实命中 `:hover`。
3. 档案条目采用“内容 + 图标操作”同行网格；删除确认仅在触发后占用下一行。
4. 扩展实验室、PDF 链接、阅读导航和文档档案真实 UI 回归；执行完整构建与 Windows 源码/成品打包验收。
