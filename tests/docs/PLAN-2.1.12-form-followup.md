# 表单交互与临时标签补充计划

1. 复用 PDF.js 原生文字字段交互层，支持字段内选择、复制、单行/多行/分格输入。查看时只读可选，编辑模块允许填写；PDF 指定只读字段始终不可修改。页面旋转、缩放、隐藏字段和同名字段同步一起处理。
2. 从最新模型字节更新原字段值及外观，不覆盖并发修改，不扁平化为图片。字段失焦提交，保存快捷键、关闭、切换及移出标签先提交；成功纳入撤销重做，失败保留原模型并提示。字段修改不重建正在填写的相邻控件。
3. 标签复用现有临时路径判断，增加琥珀色时钟图标、悬停说明和无障碍名称；原提醒关闭后图标保留，另存至正常路径后消失。
4. 新增专用单元及真实 Electron 交互测试：真实表单样本、原生值和外观、同名字段、多行中文、缺失外观、只读、长度限制、旋转、选择复制、连续填写、保存重开、撤销重做、临时标签各种状态。仅运行本次新增测试，类型检查后直接生产构建。
5. 重打包 2.1.12 macOS APP/DMG/ZIP，按用户最新要求，不运行打包后 APP 测试，仅校验交付包完整性、资源及签名。根 README 只补能力说明，不记录版本迭代。
