# 2.2.0 页眉页脚与多栏选区验收

同页跨栏拖选原来使用整页的词框阅读顺序。重复页眉页脚的排除只在跨页拖选计算时执行，导致列末尾的页脚混入同页正文复制。现在页面词框根据边缘分隔线、邻页相同位置的重复文字和紧邻的页码确定页眉页脚，两个区域仍可直接拖选。它们不参与正文栏缝推断或一键图表，跨页落在页边时按正文起止处理。

样例扩展同时发现不齐行尾可能把栏缝位置推到正文边界，短图题可能吸收贴近的正文。栏缝现在回落到实测空白通道内部，图题续行额外核对行宽和图下并排恢复的正文。

## 本轮新增检查

- 15 项单元测试通过，覆盖十种语言的重复文字和 Unicode 页码、独立分隔线、页脚近邻、保留正文与反向选择。
- 六份合成 PDF 共 18 页，包含一至四栏、窄和宽栏缝、页中及跨两栏图表、紧贴图表的正文、多行页眉页脚和左右行号。加上原件及已有脱密副本共 36 页，在三档缩放下通过 108 组自动分栏、图表边界、页眉页脚归属和正文选择核对。
- 源码窗口执行 77 次真实拖选。含 40 次正文拖选、36 次页眉页脚独立拖选和 1 次在第二页页脚结束的跨页拖选。原件与脱密副本的同页跨栏复现选区均停在页脚分隔线上方。一键图表在原件及脱密副本仍各返回 6 张图，界面语言切换共 10 种。
- 本轮仅运行新增的页眉页脚单元、PDF 矩阵和源码窗口测试，以及类型检查、生产构建和成品静态校验。README 和原件摘要一致。

合成 PDF 位于 `tests/fixtures/selection-matrix-220/`。生成入口为 `tests/scripts/make-selection-matrix-220.cjs`。测试总表位于 `tests/output/release-2.2.0-margins/`。安装包沿用 2.2.0，macOS arm64 使用临时签名。成品未启动。

## 比例输入追加验收

页面缩放确认后的数值和常态显示最多一位小数。键盘输入过程保留完整文本，回车或失焦才应用，输入不合法时保留之前的有效值。打印预览只在确认后更新。页码百分比边距、水印不透明度、PDF 字宽和 Markdown 行高沿用同一交互。新增源码窗口脚本 `release-2.2.0-ratio-input-ui.cjs` 通过五组检查，含逐键输入、取消、无效输入、缩放预设、阿拉伯数字和本地小数点。
