# 2.1.17 表格识别与正文隔离修复

最新交付为长段落三线表追加修复，见 [本轮验收](OPEN-TABLES-2.1.17.md)。以下为此前阶段记录，不代表截图中的长段落三线表已经在此前覆盖。

## 根因与修改

- 同一张表的表头、表身可能被 PDF 路径分成多个闭合网格组；原逻辑只接受与绘图边界完全一致的单个网格。多个网格被包含于“图”时又被直接丢弃，导致一键图表类型错误、缺少单元格。
- 网格最小行高和竖线段长用正文中位字号的 0.8 倍作阈值，漏掉采用较小字号的紧凑表格。改为 0.4 倍，继续要求多行多列闭合结构与足够文字占用，避免将坐标轴当表格。
- 将同一绘图中覆盖主要范围的网格合并为表格，汇总全部单元格；独立网格保留独立条目，不再因被一个图形包含而消失。
- 正文隔离按完整表格范围判断，保护合并单元格及未恢复出格子的表内文字；从格内开始选择时仍使用原有单元格边界约束。
- 居中标题与编号即使分属不同栏也能合并识别；有可靠网格证据时，允许标题与表之间存在多行说明。三线/无框表格的候选范围按实际栏域判断，避免用居中标题的 x 坐标裁掉左侧字段。
