# 2.2.0 批注文字互操作修订

- 检查原件第 2 页的正文批注和富文本的 PDF 编码，用独立解析器对照旧写法和标准 XHTML 写法。保留原件，私下验证修复结果。
- 无格式的批注只输出标准 Unicode 纯文本。有格式的批注输出 ASCII 序列化的 XFA XHTML，使用 Unicode 字符引用保留中文和补充平面字符。保留 PDFuck 内编辑所用的格式范围。
- 保存或导出时归一化可识别的旧 PDFuck 批注富文本。检查直接保存、保存取消、另存和按页导出，保留第三方批注的元数据和原有富文本。
- 重建不含原件内容的归档副本，附带合成旧格式批注以保留复现路径。用 PDF.js、MuPDF 和 macOS PDFKit 验证成品 PDF，运行本轮测试并重新打包 macOS arm64 2.2.0。

## 综合审稿和回复语言追加

- 十种界面语言都提供综合审稿要求。结尾只选四档中的一档，依据贡献、证据与修订幅度说明理由。
- 按任务取正文。润色使用选区，批注建议优先使用用户记录的选区，全文审稿使用正文，自动批注使用当前待审页。没有可靠文字时直接让模型按来源识别。保留用户指定的翻译目标。
- 验证正文主语言、少量外语引用、文件与文本两种发送方式、历史语言后缀及不同 API 模式。使用本地模拟响应，不发送原件。
