# 2.0.33 UI 修复计划

在现有 2.0.32 工作区上升级，保留已有修改，不提交或推送。

1. 模型设置：当前模型改为清晰的状态标签、配置名与模型名层级；说明独立留白，长名称、十语言、RTL 与大小字号自然换行。
2. 共用 AI 过程卡片：标题与上方进度区使用相同的小号字；保留有留白的标题分隔，用浅底内容块区分请求、思考和回复，去掉内部重复横线。取消操作独立排列，统一结果按钮与自动批注控制区间距，覆盖润色、全文点评、自动批注和批注建议。同步整理提示词输入框与隐私提示操作区，并修正过时的五分钟等待文案。
3. 验证：扩展现有真实 Electron 布局检查，检查卡片间距、按钮可达、长文本和多语言主题字号，并目视检查截图。用户在完整回归开始后明确要求按 UI 范围验收：保留已经完成的检查，跳过后续 OCR、框选等无关项目，成品仅复测模型设置和实验室窗口。
4. 交付：版本同步 2.0.33，更新打包指南、交接与验收记录，生成安装版和便携版，核验包内文件、版本与 SHA-256。macOS 在本机不构建。
