# 2.1.16 定向验收（2026-11-10）

## 实现

- 报销页的字段/表格空白不再当成正文栏缝；分栏以源文字段覆盖范围、局部连续正文和两侧行号排除为证据，避免字号、字体度量与远处图表影响。
- 表格重复横线及稀疏字段外框排除，同时保护带整页边框的正文。保留手动分栏和单元格约束。

- 算法使用 Unicode 字母类别和既有语言目录；无新增界面文案、设置或生产依赖。
