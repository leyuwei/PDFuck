# 2.1.17 阅读与批注交互追加修复计划（2026-11-13）

1. 批注删除：保留当前 PDF 页面和画布；页面生命周期内保留已覆盖原生批注 ID 的过滤集合，删除只更新模型与标记层，避免旧原生外观重新出现。覆盖单条、分组、批量、撤销/重做。
2. 弹窗：核查现有浮窗拖动，统一补齐普通模态窗口的标题拖动；输入、按钮、正文选择、缩放及视区边界继续可用。
3. 阅读工具：六个按钮使用同一线条/强调色图标风格；引文、图表、缩写采用文档独立的持久化开关及完整按钮激活色。
4. 分析任务：等待提示先显示再开始分析；切换、关闭或替换文档后丢弃过期结果；恢复文档自动启用所存功能；无结果也能关闭。
5. 搜索标题保留较小的“搜索文档”；缩写浮窗使用“缩写定义”和相应复制提示，十语言齐全。
6. 书签定位复用高亮动画，明确定位到书签起始处，重复点击仍闪烁。
7. 仅运行本轮新增单元与源码 Electron UI；使用合成或已脱敏输入。类型检查和直接构建通过后重打包 2.1.17 APP/DMG/ZIP。按用户要求不启动成品复测，仅静态核验生产资源、版本、签名、完整性及哈希。
