# 2.2.0 页眉页脚与多栏选区专项

1. 对照原件页面的页脚、正文选区和同页／跨页的选区调用链，定位漏掉保护的入口。
2. 在生成页面词框时识别有明确分隔线的页眉页脚，利用近邻页的文字和位置佐证无分隔线的重复内容。页眉、页脚各自独立选择，正文、图表和栏缝检测保留各自的字词来源。识别使用 Unicode 与版面几何。
3. 生成独立测试 PDF，涵盖一至四栏、窄和宽栏缝、页内及跨栏图表、紧贴图表的正文、复杂多行页眉页脚及两侧行号。自动分栏和一键图表逐页核对，交互测试验证正反向同栏、跨栏、跨页和直接页脚拖选。以原件和脱密归档再次核对真实版面。
4. 仅运行本轮新增的测试和必要生产构建。保持 2.2.0，校验 README 与原件摘要，生成 macOS arm64 包并做静态核验。

追加比例输入专项使用同一个可确认的数字草稿。页面缩放确认及显示最多一位小数，适合宽度和适合整页内部保留测量精度。打印缩放、页码边缘和安全边距、水印不透明度、PDF 字宽及 Markdown 行高在编辑时保留原输入，确认后应用原有范围。测试覆盖逐键输入、回车、失焦、取消、非法值和本地化数字。
