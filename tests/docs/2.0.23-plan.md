# 2.0.23 修复计划

1. 复现 AI 建议按钮的窄列排版、批注列表在首次点击后的跳动，以及回复区域双击无响应。
2. 删除 AI 建议按钮旧三列样式，使用普通横向按钮布局。
3. 编辑批注复用已有浮窗定位与拖动逻辑，限制在原生标题栏下方并设置 no-drag；增加右上角关闭、背景点击关闭及 Escape，统一取消草稿。
4. 让整个批注内容区域响应双击；指针选中条目时不触发会改变点击位置的自动滚动，保留外部定位的滚动。进一步复现并修复首次点击重绘富文本时替换文字节点、导致双击目标丢失的问题。
5. 添加真实窗口回归，覆盖窄窗口、AI 开关、拖动/窗口缩放、背景与关闭按钮、正文/回复/说明双击、部分可见条目、连续开关及保存重开；运行单元测试与 Windows 发布回归。
