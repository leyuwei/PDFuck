# 2.2.0 打印预览、图表与框选

1. 同一打印预览优先显示当前拼版 PDF，拼版或渲染失败时由 PDF.js 渲染原页，复用纸张、方向、位置、缩放、边框和页序计算。检查预览画面的尺寸、色块和切换过程中最新请求的结果。
2. 用原件第 6 页的四段矢量子图、第 16 页的越栏画布复现问题。沿同一栏向上按图题归组，以独立图题、正文间隔和面板对齐作为边界。对图框边缘的文字按完整运行或同一基线上的连续文字判断归属，保留图内短标签。
3. 合成左右越界、边界相切、多栏、紧邻图题、连续子图及独立近邻图表等样例，覆盖光栅与矢量图。用已有多语言图表标签和界面术语，补充非英语图题回归。原件重建为无原始对象和内容的布局夹具。
4. 用主题色为「打开文档」提供悬浮、按下和弹窗打开反馈，保持组内直角、尺寸和现有引导目标。检查不同主题、颜色与键盘。
5. 只执行本轮新增测试和构建检查，再生成 2.2.0 macOS arm64 的 DMG/ZIP。保留 README 和送印代码，成品只作静态校验。
