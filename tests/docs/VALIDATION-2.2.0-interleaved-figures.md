# PDFuck 2.2.0 图文交错框选验收

## 复现和修复

- 原件第 1 页的 Fig. 7 由两幅子图、旋转标签和一个独立的共用图例组成。原识别按图注与绘图对象的距离关联，先取到了图例。修复后根据两个绘图区的对齐、图例横跨两图和中间没有同栏正文等证据合并，并保留独立图注作为边界。
- 原件的 Fig. 6 图注被 PDF 的文本对象和栏缝分成几段。修复后同基线、字号匹配且连续的末尾片段纳入图注。
- 跨栏选区原先按整页栏序展开。现在横跨所有正文栏的图把正文分成几个阅读区段。两端在同一个区段时，选区留在该区段。主动跨区段时，选区按区段和栏读取正文。单栏插图或只覆盖部分栏的插图旁，正文可继续跨栏选取。

node tests/scripts/release-2.2.0-interleaved-figures-pdf.cjs
