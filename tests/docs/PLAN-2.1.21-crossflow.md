# 2.1.21 跨栏连续选区补修

用户澄清：本轮要修复主动跨栏拖选时，只选中两栏平行高度范围、遗漏阅读顺序中间内容的问题。版本号、package/lock 和 README 保持不变。

已从当前使用记录定位截图对应文件的第 10 页并复现。两栏正文共用错误的图注块标记，几何选择按高度排序裁切，仅选 14 个矩形；正确阅读范围应包含左栏剩余内容和右栏开头至终点。

最小修正放在共用选择函数：明确的普通跨栏范围转为阅读顺序；阅读顺序不因非跨栏的块标记漏掉目标栏上方正文。图表、真正跨栏结构、单元格选择继续使用原规则，不更改源 PDF。

新增小型单元先证明旧代码失败，再对原页和脱密副本进行三档缩放/两种字体、正反方向、同高度及不同高度终点检查；源码窗口验证跨栏拖选覆盖左栏底部及右栏上方。仅执行本轮新增测试、类型检查、直接构建和新增静态包检查。重打同版本 macOS arm64 APP/DMG/ZIP，保存此前产物备份。
