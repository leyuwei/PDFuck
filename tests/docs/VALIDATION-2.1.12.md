## 根因与修改

**原生表单填写内容不可见。** 阅读画布原先使用 `AnnotationMode.DISABLE` 避免自绘批注重复，但 Widget 的填写内容也存于注释外观中。现在保留 PDF.js 的正常原生渲染，通过原始 PDF 引用 ID 精确过滤软件覆盖层已接管的注释指令块；表单及外部 FreeText 继续显示。原始表单结构、填写值和外观引用保持不变，不将用户 PDF 扁平化。文字、图像、页码、水印及普通批注记录传递原始引用 ID，避免重复绘制。

**打印拼版的同类丢失。** embedPage 不包含注释；临时打印副本现在压入可打印的原生外观，使用勾选/单选当前状态，并把外观 Matrix 应用后的 BBox 放到正确位置。缺失外观的字段先补建。刚补建的外观是 PDFContentStream，不能只接收从文件读取的 PDFRawStream；此差异已纳入新测试。打印准备只修改副本。图片导出同时使用完整的 CMap 和标准字体资源配置。

**表格文字跨单元格。** 以前只有整图/整表隔离，没有格子边界。现在从真实绘图路径和细长填充条提取横竖规则，沿用 Form、矩阵、路径裁剪和页边界，归并分段规则，推导闭合单元格及合并单元格。重复网格必须含足够文字，图片、单框、空背景、稀疏坐标网格及普通正文不作为表格；明确归组的分图保持原图索引。

文字映射记录起始单元格和边界。拖选、双击、键盘延伸及跨页操作保持格内范围，格内多行按视觉顺序读取。光标先确定纵向文字行，避免短末行的右侧空白被上面的长行抢走；空格子不选择邻格。高亮矩形裁到单元格内。正文跨表选择跳过整表；精确搜索和 AI 原文引用不套用指针选择的单元格约束。

**新增文字顶部截断。** 原 Canvas top 基线并不保证墨迹在画布内：实测默认 Arial 16px 中文向上伸出约 0.79px，重音字母约 1.94px。现在复用同一文字位图方法，使用 alphabetic 基线和实际字形升部，保留像素余量。添加、重编、调整文字框及保存外观共用此方法；普通标准 PDF 字库的英文分支继续保留。文字框仍按用户设置的范围和排版处理溢出。

**README。** 根 README 已改为中英文功能、使用、安装、开发及数据处理说明，移除软件版本号、迭代记录、修复回顾、版本测试命令及验收入口。版本过程只保留在测试文档和打包指南。
