## 上一轮需求复核记录（历史）

此记录替代上一轮验收结论。上一轮图题夹具替换了标记词，未覆盖图题整段、正反方向和重复点击；打印只将 PDF 内容转成图片，仍可能走设备 PDF 直通，不能视为打印问题已定位。

## 八项需求的实现与证据

1. 引文性能：每页文字索引只构建一次，链接直接取字符几何，避免每条引文执行完整指针选区算法。离屏页面不因有引文就请求完整文字布局，离屏链接也不创建 DOM。41 页合成文档开启引文后仍只有 2 页完整文字布局；新增性能脚本记录滚动帧间隔与真实拖选。
2. 内部链接返回：记录原页和页内偏移，悬浮按钮恢复原位置；UI 断言返回后的实际 scrollTop，及黄色提示条与按钮边界不相交。临时目录提示独立布局，换行也有空间。
3. 列表闪烁：正文选择批注会定位并闪烁条目，focus token 使重复点击同一条目也再次闪烁。UI 监测真实 animate 调用至少两次；减少动画偏好继续有效。
4. 批注 hint：替换原生 title 为应用内浮层，悬停及键盘焦点显示内容，支持方向属性、换行和最大高度；UI 检查真实 tooltip。
5. HP 打印：用户确认故障设备为本机 HP LaserJet M1536dnf。其 PPD 明确声明 `application/vnd.cups-pdf application/pdf 0 ... -`，允许 PDF 直接交给设备解析。图片 PDF 仍走此路径，因此上一轮处理不足。本轮按驱动声明检测 URF 支持，使用 macOS cupsfilter 在电脑上生成 `UNIRAST` 数据，再交给 lp；不改系统队列、驱动或 PPD，保留单面/长边/短边选项，不复制份数。光栅转换失败会报错，不静默退回该驱动的 PDF 直通。其他不支持 URF 的驱动继续接收兼容图片 PDF。软件数据路径已验证，设备重启是否完全消失仍需实机出纸确认。
6. 删除残影：删除成功后更新 PDF 字节并重新载入底图，防止旧原生批注外观重现；模型删除幂等，UI 检查条目、页面覆盖与重载完成。
7. 缩写快查：正文链接、结果清单与浮窗复用引文设计。Unicode 首字母、全角括号、正向和反向定义、多语言译名、同名重新定义、所有出现位置及单词内部误匹配均有新增测试。识别是启发式，扫描页需先 OCR；不能宣称自然语言的所有歧义定义均可精确识别。
8. 框选与分栏：全局正文交叉证据排除局部伪栏缝。修复带冒号及罗马数字的图表题标记；图题连续行最终归属避免被另一栏的结构组覆盖；完整图题关联同一可视区域，保证正反向选区一致。脱敏夹具现在保留标准图表题标记，重新提取六份输入共 18 页几何。

## 新增验证

- 36 项新增单元全部通过。18 页各三档缩放、正反输入共 108 种栏识别组合；另含 1,000 个重复链接的文字几何索引检查。
- `release-2.1.17-selection-review.cjs`：1,038 组正文跨行、30 组完整/局部图题范围，全部逐词几何覆盖，并检查反向选区一致。图题 oracle 由源标记、字号、基线、图形邻近关系定义，避免用被测 visualBlock IDs 当答案；独立公式的小括号上下缘不当作正文行。
- `release-2.1.17-print-filter.cjs`：本机真实 HP PPD 和系统过滤器，合成两页发票包含文字及透明图形，单面/长边/短边分别输出有效 URF，页数都是 2；不发送打印作业。
- 源码与成品分别执行新增 UI 和 41 页引文性能脚本；结果在 `tests/output/release-2.1.17`，使用合成文档及独立用户配置。
