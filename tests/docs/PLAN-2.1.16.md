# 2.1.16 定向修复计划

1. 共享布局：修复报销单的错误分栏及中文跨行漏字；栏缝需有局部正文证据，行号、表格和符号列不能充当正文栏。
2. 跨栏选择：光标按局部行定位，跨栏表注保留右半行；正文范围排除上方跨栏公式，保留公式内部上下标及正反向一致性。
3. 水印：在选择输入处排除带水印标记及叠加的半透明/重复倾斜文字，保持页面渲染和编辑数据。保护普通旋转文字、竖排、正文及行内公式。
4. 隐私：新输入匿名归档；审查并处理全部公开 PDF 夹具的正文/身份、元数据、批注、表单、附件和图片内容。私有原件仅在已有忽略目录备份，用户原件不改。历史 Git 内容不自动改写。
5. 新增定向单元、真实 PDF 布局/逐字选区、源码及成品 Electron 拖选、十语言检查。只执行新增项、typecheck、直接生产构建、diff 和新增包检查；不调用全量 build/test。
6. 同步 2.1.16，交付 macOS arm64 APP/DMG/ZIP、校验值和验收记录。Windows、可信签名和公证如未执行须明确记录。

影响入口：text-layout / PdfViewer 的页面与离屏选择缓存、page-visuals 的图表隔离、测试夹具/脚本、版本清单与打包文档。无新增用户设置或依赖。
