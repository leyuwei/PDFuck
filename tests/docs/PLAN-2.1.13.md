# 2.1.13 修改计划

本版聚焦三个相关的可用性问题：无文档时仍可从文件合并 PDF；外部拖入不属于 PDF/TXT/MD 的文件时，以既有确认弹窗样式询问是否转换，并复用文件导入与合并链路；实验室功能窗口统一支持拖动、调整尺寸、视口边界保护和尺寸持久化。

实现范围：

1. 增加主进程到渲染进程的单文件导入 IPC，沿用 `openPdfImports()` 的格式转换逻辑；合并入口只在只读状态下禁用。
2. 外部文件拖放按扩展名分流。PDF、TXT、MD 直接打开；其他文件显示十语言转换确认，确认后导入并进入原有合并流程，失败仍沿用已有错误提示。
3. 为实验室主窗口、AI 设置、翻译设置/结果、免责声明和画板加入独立尺寸 key；共享浮窗 hook 负责恢复、限制、拖动、ResizeObserver 持久化和窗口缩放后的重新布局。正文区域滚动，标题栏负责拖动，底部操作区保留稳定间距。
4. 增加定向单元测试，覆盖尺寸边界、localStorage、无文档合并入口、多语言文案、拖放导入链路和实验室窗口布局契约。

版本、锁文件、测试脚本和 macOS arm64 打包产物统一为 2.1.13。首轮计划只运行本版新增单元测试、typecheck、直接生产构建、diff 检查和静态包验收；此为历史计划，本轮执行范围以下方补充为准。

## 普通弹窗范围修复（2026-11-03）

OCR 的共享样式被“关于”复用，却错误加入实验室的最小高度和 resize；普通批注也被错误加入实验室尺寸 key。恢复 OCR 的组件和 CSS，以及普通批注的 hook/布局到升级前的行为，保留普通批注原本就有的 resize。不为“关于”单独叠加覆盖样式，不改变导入、多语言和实验室提示词伸展布局。

新增 UI 测试还发现后加载的工具面板滚动条规则覆盖实验室样式，造成右侧多留 15px；提高实验室选择器优先级，并为实验室翻译结果正文取消无滚动时的预留槽，不修改全局或普通弹窗规则。

新增 `tests/scripts/release-2.1.13-dialog-scope-ui.cjs`，本轮只运行该新脚本。在源码 Electron 中检查十语言下“关于”的内容高度与非缩放行为、OCR 非缩放与忽略旧尺寸、普通批注忽略误写尺寸，以及实验室窗口调整后提示词增高、对称边距、控件间距和尺寸恢复。修正首轮用例错误将 OCR/普通批注归为实验室的断言，但不重跑首轮用例。另做 typecheck、生产构建和 diff 检查，再重新生成 macOS arm64 APP/DMG/ZIP、签名及 SHA-256。按用户最新要求，成品不复测，也不运行静态包验收脚本。
