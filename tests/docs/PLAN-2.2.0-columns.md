# 2.2.0 自动分栏修订

1. 用同一 PDF 的原件与脱密副本逐页比对 PDF 绘制横线、真正的栏缝和界面分栏导线，定位漏检、错位与额外导线。
2. 让局部闭合图框只在自己的纵向范围内提供结构证据，将图框边缘与独立的无竖线表格规则分开。保留紧栏缝、三栏、实际边栏和局部字形选择。
3. 以正文相近字级、有效文字跨度和连续行作为栏缝证据，避免脚注间距及同一图中的标签推动导线。界面和实际词框应用同一自动边界，手动覆盖及恢复自动继续沿用原入口。依据字形几何及 Unicode 字母分类，不绑定界面语言。
4. 仅运行本轮新增单元与源码窗口检查。新增用例应覆盖原件与脱密副本的九页、相同版面横线的构造样本、真实三栏、图表或表格与正文、左右分开拖选、缩放和手动恢复。
5. 校验原件与 README，保持 2.2.0，重打 macOS arm64。成品只做静态校验。
