# PDFuck 2.1.2 验收记录

日期：2026-10-05。环境：Windows x64、Electron 43.4.0、electron-builder 26.15.3。清单与锁文件同步为 2.1.2，无新增依赖。

## 改动

- 去掉源码输入框与分栏拖动把手的焦点边框，保留键盘编辑、分栏方向键及 Home 复位。
- 增加与周围按钮等高的 36px 同步滚动开关。默认关闭，双栏按阅读进度双向联动，兼容连续和单页 PDF、页码导航、预览重新生成；单栏禁用并保留偏好。联动按滚动进度估算，不逐行匹配 Markdown 与 PDF。
- 源码输入、粘贴和格式插入进入独立的每文档历史。连续输入在 800ms 内合并，撤销恢复选区，新编辑清空重做；保存、生成 PDF 及切换标签保留历史。顶部历史按钮按最近操作或激活的源码/PDF 区域工作，PDF 编辑仍使用原有历史。支持 Ctrl/⌘+Z、Shift+Z 和 Ctrl/⌘+Y，输入法组字期间不撤销。历史最多 100 个快照/约 800 万字符，至少保留最近一步，不跨进程保存。
- 源码字号为 S/M/L（界面正文的 90%/100%/120%），独立于 PDF 排版。字号控件融入底部状态栏，始终单行；窄于 420px 的源码栏隐藏保存快捷键说明，字符数过长时截断。字号和同步开关跨文档、重启持久保存，旧偏好自动使用默认值。
- 新控件采用现有主题变量、界面字号与十语言目录。Windows 沿用 2.1.1 的 Logo、安装状态提示与稳定 appId/GUID，README 和 PACKAGING_GUIDE 同步升级说明。
