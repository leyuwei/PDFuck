# 2.0.36 验收与交付记录

Windows x64，2026-09-17。

## 改动

- OCR 入口现在区分关闭、打开和缩小状态；窗口缩小时显示与批注/实验室一致的琥珀色提示，恢复后回到打开态样式。
- 左侧栏底部固定以两行显示“关于”和 `v2.0.36`。
- 标题栏加入固定 30px、与界面字号解耦的蓝底纸张小鸭 Logo；SVG、PNG 和多尺寸 ICO 均由仓库脚本确定性生成，在明暗主题下保持轮廓清晰。
- PDF.js 目标解析支持命名目标、直接目标、XYZ/FitH/FitBH/FitR 纵向位置及旋转页面坐标。内置书签可保留并打开 URI，页面 Link 注释形成可访问点击层；单页和虚拟化长文档会等待目标页挂载后定位。
- 外部书签和链接经主进程安全桥交给系统，仅允许 `http`、`https`、`mailto`，拒绝 `file`、`javascript`、`data`、控制字符及无效地址。
- 新增链接相关提示覆盖简体中文、英语、日语、俄语、西班牙语、法语、德语、葡萄牙语、韩语和阿拉伯语。
