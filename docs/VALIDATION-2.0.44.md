# PDFuck 2.0.44 验收记录

## 范围

按用户要求，仅执行 2.0.44 新增专项测试；另外执行 TypeScript 类型检查、生产构建和 Windows 成品核验，不运行既有全量回归。

## 根因与修复

- 打印遗漏编辑元素：文字、图片和图形均以 PDF 注释及外观流保存，而打印拼版使用的 `embedPage()` 只嵌入页面内容流，不复制注释。因此打印拿到的是原始页面内容。现在打印入口会在内存中的临时副本里把 PDFuck 文字、图片、图形、页码和水印外观压入页面内容流后再拼版；原模型、保存文件及撤销历史均不被扁平化。
- 页面批量删除：模型和最终应用动作原本已支持同时保留/删除多个页面，但页面管理浮窗只有逐页按钮。现复用既有页码范围解析器，支持输入 `2-4, 6` 等逗号与范围组合，一次标记多页，并继续与排序、旋转统一应用和撤销。
