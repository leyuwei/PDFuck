## 功能与边界

- 打印窗口不再套用会把正文整体滚动的通用容器。左侧设置独立滚动，右侧预览和底部操作留在固定区域，预览纸张保持比例，随窗口可用空间缩放。
- 实验室模型设置移除最小化按钮与对应状态，仅保留关闭。智能润色、全文评价、自动批注、独立批注建议、画板和实验室隐私提示默认靠右下角；功能窗口与画板仍可拖动，已有文内嵌入式建议保持原位。
- “文档标签”可点击，档案浮窗贴在其下方。支持多个命名档案、改名、删除、重启后恢复；删除档案不删除文件。存储只保存当前窗口的文件列表，不保存未落盘文档或未保存修改，界面有明确说明。
- 恢复逐个打开，沿用密码和阅读位置流程；已打开文档不重复打开，现有标签及其编辑状态保留。缺失、访问失败、打不开或取消打开的文件集中列出，其他文件继续恢复。
- 档案数据使用本地存储，写入前重新读取以保留其他窗口较早的修改；存储损坏或写入失败时显示错误，不覆盖原数据。档案不会跨设备复制 PDF。
