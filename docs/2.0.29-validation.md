# 2.0.29 修复与验证记录

## 修改与原因

- 批注人按钮原固定为 27px，单双行按钮按文字自动撑高，且两者行高/内边距不同。现在统一最小高度、行高和内边距，并让单双行文字继承按钮字号；单行、多行两种状态均按同一规则显示。
- 搜索快捷键的行高、边框和内边距提高了按钮的自然高度。现在利用按钮已有纵向留白容纳键帽，“阅读工具”五个按钮共用等高网格；长译文可换行并提高整组高度，不裁切或缩小字体。
- ScrollWindow 增加可选闲置隐藏，仅 ToolPanel 的四个模块启用。鼠标、滚轮、滚动、焦点、键盘操作会显示原生滚动条，1.5 秒后隐藏；活动按压/拖动期间保持可见。只改变滚动条颜色，保留稳定滚动槽和滚动位置；强制颜色模式使用系统颜色。
- 复用原生滚动条和现有 ScrollWindow，无新增依赖，无自定义滑块或滚动位置同步逻辑。其他弹窗保持原来的滚动条行为。
