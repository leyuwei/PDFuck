# PDFuck 2.1.0 验收记录

环境：Windows x64，Node.js 22.22.2，Electron 43.4.0，electron-builder 26.15.3。版本在 package.json、package-lock.json 根记录和应用记录中均为 2.1.0，无新增依赖。

## 功能与界面

- `.md`/`.MD` 接入命令行、系统文件事件、打开对话框、拖入、最近文档、档案和多窗口。Windows 安装关联声明 Markdown Editor；macOS 文档类型及 Markdown UTI 已声明。
- 默认源码与真实 PDF 双栏；鼠标或键盘调整分割线，关闭任意栏后随时恢复，比例和模式持久化。源码与 PDF 使用独立保存路径，关闭时检查双方未保存内容。
- 源码、PDF 面板使用 36px 单行标题，去掉编号及重复提示；单栏不显示面板标题，源码保存/另存为移至语法工具栏。PDF 排版与快捷插入复用已有可拖动浮窗和滚动样式，底部操作栏固定，不使用折叠菜单。
- 快捷插入覆盖 14 类：标题、加粗、斜体、删除线、行内代码、无序/有序列表、任务、引用、代码块、链接、图片、表格、分隔线；提供六级标题、代码语言、表格行列和生成语法预览。
- 五种 A4 模板分别设计标题、引用、代码、表格、列表和分隔线样式；所选模板及每个模板的字体族、字号、行距、段距分别持久保存，旧记录自动迁移。源码自动生成保留可选择文字的 PDF。已有 PDF 编辑/批注时暂停自动重建，显式刷新先确认。
- 顶部文件夹按钮使用 SVG 图标，保留多语言提示和无障碍名称。语法图标不换行，尺寸随界面字号变化；浮窗高度、内边距、长译文和 RTL 均检查。隐藏 PDF 的零宽度不会触发缩小页面。
- 顶部操作按钮、撤销/重做组和页码输入框统一为 36px 高，移除导致高度各异的自动高度及纵向内边距；启用、禁用和四档字号均保持上下边缘对齐。
