# 2.0.22 交付与验证记录

日期：2026-09-07。基于 main 的 4c372c2，修改保留在当前工作区，本轮未提交或推送。

## 修改结果

- 标题和滚动内容使用独立容器，修复 sticky 标题仍被同一滚动条覆盖的根因。覆盖实验室窗口、模型设置、批注人设置、画板、图形窗口、侧栏及各类弹窗。
- 批注列表双击内容与 PDF 页面双击批注共用“编辑批注”弹窗；删除原位编辑、右侧设置按钮及其面板代码。批注建议入口移入弹窗。
- 正文与回复按内容展开，窗口可调整尺寸。支持选中文字设置粗体、斜体、下划线、高亮及 Ctrl/⌘+B、I、U、Shift+H；有简洁按钮和快捷键提示，覆盖十种界面语言。
- PDF 保留纯文本 Contents，并保存经过校验的样式范围和标准 RC 富文本。保存重开、撤销重做、局部取消样式、跨页批注同步更新均有回归。
- 统一 AI 恢复替代固定三次重试：网络、限流与临时服务错误退避重试；短输入超时适当放宽单次时限；大输入超时或容量超限分批；输出截断增加预算至服务支持范围；不兼容参数按具体拒绝信息调整；结构错误纠正后重新校验。
- 恢复显示原因与动作，可随时取消。总恢复预算为设置超时的两倍，最低 30 秒、最高 5 分钟；全文评价倒计时使用同一预算。密钥、账户余额、证书等无法代为解决的问题会报错，不盲目重试。
- 自动批注分批后重新映射重复引文的原始位置，全部结果校验通过后才写入；写回失败不会重放模型结果。
