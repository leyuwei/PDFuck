# 2.0.27 实施计划

1. 左侧导航使用十语言的简短模块名称，保留完整无障碍名称与悬停提示。导航宽度随字号调整，正文标记可自然换行，展开/收起的父容器同步尺寸，不裁切长译文。
2. 单行/多行按钮使用原生 SVG：一行横向文字笔画表示切换到单行，多行笔画表示切回多行；复用当前切换逻辑与翻译。
3. 标准预设的辅助/正文/标题从 12/14/18px 调整为 11/13/17px，其他预设保持原值；保存的标准设置继续识别为标准，预览数值与实际 CSS 一致。左侧分组标题使用正文档和字重区分，窗口/模块标题保持标题档。
4. 扩展四预设/十语言/四模块测试，检查导航文字 Range 边界、展开和收起、分组标题层级、图标与切换、旧设置兼容。构建、回归并验证 2.0.27 Windows 成品。
