- 十种语言移除“从文件合并 PDF”“管理页面”“在页面上添加图片”“在页面上添加图形”的尾部省略号。
- 文档标签栏和标签外框从固定高度改为内容自适应，PDF 徽标与文件名垂直居中，内外框均保留上下留白；数字计数使用居中布局和自适应胶囊，单数字呈圆形，多位数字正常扩展。
