# PDFuck 2.0.52 验收记录

验收日期：2026-10-02。按用户要求，仅运行本次新增测试和必要静态检查，没有执行全部旧测试、`npm run build` 或一键发布脚本。

## 实现范围

- 润色、全文评价、自动批注、批注修改建议、图片解释、翻译六种 AI 功能提供独立 PDF 报告：生成时原文快照、Markdown 排版结果及完整 Markdown 原文。另内嵌 `response.md`、`source.txt` UTF-8 附件，避免部分阅读器复制 RTL 字形时改变原文；图片解释包含源图片，全文评价追加生成时的原 PDF 页面。报告使用隔离、禁脚本的 Electron 页面进行真正分页打印，可选择正文文字，不新增依赖。
- AI 生成正文和回复分别保存 `PDFuckAI`、`PDFuckReplyAI` 来源字段。列表、纸张批注位置和文内卡片均显示渐变星形 AI 徽标；编辑、保存、重开、撤销保留正确来源。旧的普通批注不依据作者或文本猜测来源；原有 `ai_polish` 类型继续可识别。
- `pdfuck.annotation-view.v1` 保存 Markdown 和列表/文内查看方式，同窗口控件共享变化，独立窗口订阅 storage。默认保持列表和原文字样。编辑器保留原始 Markdown 与富文本编辑，勾选后显示预览；正文、原因、回复在列表和文内卡片复用同一偏好。
- 单行模式把整条批注的正文、原因与回复压到唯一一行，溢出省略；Markdown 的段落、列表、表格和代码块不再各占一行。书签展开/收起全部按钮改为 SVG 方向箭头与层级线，保留可访问名称。
- 批注工具栏最上方可切换查看方式。文内模式隐藏右侧列表，单击批注显示贴近位置的卡片，含作者、三种状态选择、正文、原因与回复；双击打开原编辑窗，也提供键盘可达的编辑和关闭入口。卡片随缩放、视区与字号调整，长内容内部滚动。每页纸张左上方外侧显示未处理、已处理、想一想、不做了四类数量，统计区域在纸张外布局。
- 新控件覆盖十语言、RTL、四档预置字号及明暗主题，字号仅引用统一的辅助/正文/标题变量。静态审计同时补齐两条原有未翻译错误/状态提示，并将 AI、W、mm 记为语言无关的标记或单位。

## 2.0.52 界面修正版

针对用户截图反馈，先完成归因再修改共享组件，保持版本号 2.0.52，不新增依赖。

| 问题 | 根因 | 修复与关联覆盖 |
| --- | --- | --- |
| 工具栏 Markdown 复选框异常巨大 | 通用 `.tool-panel label/input` 的优先级高于新控件，继承网格排版、全宽和固定高度 | 同一共享选择器覆盖工具栏和编辑窗，复选框为 `1em`，圆角浅色设置行配合主题色勾选/选中底色和键盘焦点，横向对齐、长文本可换行 |
| 文内卡片遮挡批注、不自动消失 | 原定位在视区夹取坐标，空间不足时移回批注范围；没有外部点击监听 | 使用整条批注矩形范围选择右/左/下/上四块空位，狭窄空位收窄/限制高度，长内容滚动；覆盖整个视区时在批注下方保留可读宽度并滚动显露；文档级捕获监听关闭外部点击，保留卡片状态按钮、选择其他批注和编辑窗操作 |
| Markdown 字号不跟列表改变 | Markdown 标题、代码、表格引用全局字号，后来加载的排版规则还会再次覆盖标题 | 注释专用的 Markdown 元素继承区域字号，正文、原因和自定义回复一致，实验室 AI 报告排版不变 |
| 页面盖住黄底警告 | 活跃页面与警告同为 z-index 40，后绘制的页面及其内部层级越过文档提示 | viewer 建立独立堆叠上下文，文档提示高于所有页面内层；卡片可用区域也避开临时文件/安全提示 |
| 空正文仍显示预览边框 | 编辑窗仅检查偏好，未检查正文 | 正文与自定义回复统一检查 `trim()`，仅非空且开启 Markdown 时显示预览，清空后立即移除 |
