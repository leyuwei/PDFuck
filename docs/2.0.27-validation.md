# 2.0.27 修复与验证记录

日期：2026-09-08。继续在 main（ee70bd1）既有工作区上升级；保留此前修改，本轮未提交或推送。

## 修改与根因

- 导航溢出来自固定 76px 宽度直接展示完整模块译名。改用十语言简短导航名称，保留完整 aria-label 与原有悬停提示；导航宽度随正文档在 76–112px 范围内调整，展开与收起父容器复用同一变量。文字使用辅助档，允许必要换行。移除外层宽度动画，避免字号预览期间发生瞬时裁切。
- 批注单行按钮原来使用三个横线的 Unicode 字符，含义与“单行”不符。现在用 SVG 的一行文字笔画表示单行，三个基线表示切回多行，继续复用原有状态、文案及操作逻辑。
- 标准预设的辅助/正文/标题调整为 11/13/17px，分别比之前小 1px；其他三个预设保持原值。已有存储标识 14 继续代表标准，统一计算 CSS 与弹窗预览数值。
- “页面布局”“主题”等灰色分组标题此前被全局 h3 标题规则放大，现使用正文档和 650 字重；标准下为 13px，模块和窗口标题仍为 17px，不新增第四种字号。
