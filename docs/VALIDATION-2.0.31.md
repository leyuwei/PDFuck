- README 保留核心亮点，恢复安装配置、架构、开发入口及开源致谢，中英双语，不添加版本流水账。

## 范围与限制

- OCR 适用于扫描文字；低清晰度、变形文字、手写及复杂公式的识别准确性仍需人工核对，不保证逐字正确。
- 单页按 300 DPI 渲染，超大页面限制在约 1600 万像素；不改变源页面图像。
- 未运行 macOS 原生打包、签名、公证或 Windows 实际安装/卸载；macOS 发布脚本已接入同一 OCR 回归。
- 生产依赖审计无已知漏洞；本机 npm 审计另报现有开发测试/打包依赖的 3 项问题（Vitest/@vitest/mocker、js-yaml），它们不在应用生产依赖中。本次未执行跨范围强制升级。
