# PDFuck 2.0.43 验收记录

## 范围

本次只执行 2.0.43 新增专项测试，不运行既有全量回归；另外执行 TypeScript 类型检查、生产构建和 Windows 成品核验。

## 修复与根因

- 新增文字：文字对象现在提供四角缩放柄，拖动时约束在页面内；中文和非标准字体拖动期间使用同字体、同字号的实时 DOM 排版，不再拉伸旧 PNG，松手后再按最终尺寸生成外观流并写回 PDF。
- 临时文件：在目录名任意位置匹配 `wechat`、`tmp`、`temp`、`qq`、`msg`、`chat`、`tencent`、`slack`、`feishu`、`dingding`、`linshi`、`deprecate`、`archi` 等提示词；文件名自身不参与判定。Ctrl/⌘+S 对命中文档进入“另存为”，工具栏的显式“保存”语义不变。
- 页面管理：通用滚动窗体曾破坏弹窗网格的高度约束，使内部页面列表虽显示滚动条却接收不到有效滚轮滚动；现恢复 `minmax(0, 1fr)` 约束和内部滚动。
- 文档标签：空间足够时按完整文件名的自然宽度显示；只有总宽度不足时才切为固定宽度的紧凑标签，并保留横向滚动。
- 水印预览：预览页按真实页面比例自适应可用区域，不再受旧的 252 px 缩略图上限限制。
- 大文件打印：旧流程一次性嵌入并序列化全部所选页面，随后 PDFium 默认按 600 DPI 建立整页 BGRA 位图，导致源文档、全部嵌入页、输出缓冲与巨幅位图在内存中重叠。现改为小批次顺序排版/派发、默认 300 DPI，并按纸张面积把单页位图预算限制在 64 MiB；双面任务保持偶数张批次，份数在多批任务中按完整副本顺序展开。
