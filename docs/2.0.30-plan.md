# 2.0.30 实施计划

1. 自动批注选项明确区分标题与说明字重，十语言、四档字号检查，保留标题强调。
2. 编辑批注与 AI 建议共用一个可拖动、可缩放窗口。AI 阶段提供返回编辑入口，保留内容、格式、颜色、回复草稿；采用建议仅填入回复，最后确认才写入 PDF。复用现有 AI 上下文、进度、恢复和取消逻辑。AI 阶段允许在 PDF 中选择上下文，关闭或返回时结束该阶段请求，避免迟到结果串入其他批注。
3. 窗口增加的高度分配给正文编辑区；长文本继续随内容扩展并通过窗口正文滚动。缩小时控件换行，标题固定，确认按钮不悬在大片空白上方。
4. 增加尺寸、多语言字重、草稿保存/取消、AI 失败/重试/返回/关闭回归；运行构建与既有回归，生成并校验 Windows 2.0.30 成品。
