# PDFuck v1.7 设计与架构

版权：Copyright © 2026 github@leyuwei

## 1. 产品结构

界面只保留查看、编辑、批注、保存四个模块：第一行是文件/页码/缩放和窗口控制，第二行是单窗口文档标签栏；左侧为模块与工具，中央为 PDF 画布，批注模式右侧显示可行内编辑的批注列表，底部显示状态和文字选区。

窗口采用无系统外框设计。最小化、最大化/还原和关闭按钮使用独立固定区域置于最右上角，不随中间工具栏宽度移动；标题栏空白区域可拖动窗口。

## 2. 跨平台技术架构

- Electron 43：Windows/macOS 桌面窗口、文件对话框、启动参数与文件落盘。
- React 19 + TypeScript：四模块界面和交互状态。
- Vite/electron-vite：开发、类型检查和生产构建。
- PDF.js：PDF 解析、文字信息和高 DPI 页面渲染。
- pdf-lib：裁切、删页、文字叠加、标准 PDF 批注字典和序列化。
- Canvas：PNG/JPG 编码；RGB PostScript 图像流用于 EPS。

数据流：PDF 字节由主进程读取，经受控 IPC 交给渲染层；pdf-lib 保存编辑模型，每次修改后重新序列化；PDF.js 使用新的字节刷新画布与文字层。业务代码不使用 Windows 专属 API。

多文件采用单 BrowserWindow、多文档会话：主进程始终复用唯一主窗口，文件关联和第二实例参数通过安全事件交给现有渲染器。每个标签保存独立 PdfDocumentModel、页面数据、页码、缩放、工具、批注选择和未保存状态；切换标签时恢复对应会话，关闭标签不影响主窗口及其他文档。

## 3. 进程与安全边界

- Renderer 设置 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`。
- Preload 每个桌面动作只暴露一个明确方法，不透传 `ipcRenderer`。
- Main process 校验 PDF 扩展名、导出格式、IPC 发送者和目标路径。
- 覆盖保存先写同目录临时文件，再重命名或覆盖替换。
- 禁止渲染层跳转外部页面和创建新窗口；页面使用限制性 CSP。
- 所有 IPC 都校验发送者必须是唯一主窗口；文件对话框和临时打印窗口绑定该主窗口。
- 外部文件关联、第二实例参数、拖放和再次打开只新增文档标签；关闭主窗口时统一检查所有标签的未保存修改。

## 4. 查看器

缩放交互先用 CSS 对现有画面即时预览，再在 140 ms 稳定窗口后请求 PDF.js 高清重绘。只有可见页和上下约 800 px 的邻近页面参与重绘；后台 canvas 完成后才原子替换可见画面，避免重设尺寸造成白闪。单页画布设有 1200 万像素内存预算，高倍率下仍从 PDF 矢量源重绘。

连续模式渲染纵向页面栈并随滚动更新当前页；滚动计算与 Ctrl+滚轮缩放均按动画帧合并。单页模式只挂载当前页。

文字层从 PDF.js TextContent 生成按阅读顺序排列的单词框，并仅在页面首次接近视窗时提取。四个功能模块的普通页面状态都启用字符级定位：单击按字符宽度吸附到最近字符边界，拖动两端均使用字符偏移生成精确矩形；左右方向键逐字符移动，按住 Shift 时从固定锚点扩展或反向收缩，并可跨单词连续选择。页面坐标以左上角 PDF 点为统一内部坐标。

复制使用渲染层统一清理文本，再通过受控 IPC 写入系统剪贴板：PDF 硬回行会被移除，英文词间保留空格，中文连续行不额外插入空格，常见英文断行连字符会自动修复。右键菜单和 Ctrl/Cmd+C 共用同一条处理链路。

## 5. 编辑与批注

- 裁切：第一次拖动只创建草稿框；草稿框支持整体移动、四边和四角八方向缩放，并被限制在页面范围内。点击“确认范围”后才触发二次询问，确认后将最终画布坐标转换为 PDF CropBox。裁切成功后工具自动复位，下一次点击裁切按钮会明确开始一轮新操作，避免重复点击意外关闭工具。
- 删除：使用页码多选视窗批量选择，按倒序一次删除；禁止删除全部页面。
- 添加文字：保存为带唯一编号和外观流的 FreeText 对象。拉丁文字使用矢量标准字体外观，中文等字符使用三倍分辨率透明外观；应用覆盖层支持拖动和双击再次编辑完整格式。
- 文本批注：Highlight、Underline、StrikeOut 和替换主题，使用 Rect 与 QuadPoints。
- 位置批注：Text 与 Caret；插入点吸附到最近文字边界并显示小型插入符。
- 批注均写入 Contents、T、NM、M、C、Subj 等标准字段，可保存后重新解析。
- 页面覆盖层负责选择、拖动、双击编辑和右键编辑/删除；列表内容单元格负责双击行内编辑。
- 列表选择把持久的列表选中编号与短暂的页面聚焦编号分开管理。目标批注自动滚动到视窗中央，每个 Rect 分段绘制紧贴文字的轮廓和“当前批注”标签；动画约 0.95 秒，1.05 秒后节点从 DOM 移除，重复点击可重新触发。
- 右侧批注列表可在 342 px 完整视图和 46 px 窄栏间切换，中央文档区随 Flex 布局自动扩展或恢复。
- 六类批注在工具栏、右键菜单和批注列表中使用同一套语义化 SVG 图标。

## 6. 保存与导出

- PDF：保留页面编辑与标准批注。
- 打印与导出共用页码选择器：默认全选，支持当前页、奇偶页、反选、清空、逐页点选，以及 `1-3, 5, 8-10` 范围输入。
- 打印和 PDF 导出使用 pdf-lib 复制所选页面生成内存子集，不修改当前文档，并保留所选页上的标准批注。
- PNG/JPG：仅把所选原始页交给 PDF.js 按 72-600 DPI 渲染，再由 Canvas 编码。
- EPS：所选页面分别写入 EPSF 文件，包含 BoundingBox、RGB colorimage，并使用原始页码作为稳定后缀。

## 7. 验收

- TypeScript 严格检查、Vitest 文档模型/几何/EPS 测试。
- 示例 PDF 实际桌面检查：连续查看、四模块字符级鼠标拖选和 Shift 方向键选字、右键/快捷键去回行复制、可移动缩放裁切框、高亮说明、1 秒分段聚焦、侧栏收起、右键菜单和批注列表行内编辑。
- 生产 EXE 连续接收两个 PDF 时只能有一个主窗口和两个文档标签；无外框和右上角窗口按钮截图检查。
- Windows 输出为 portable EXE；macOS 预置 DMG 配置，需在 macOS 上执行签名与公证。

## 8. 更新检测

主进程启动后由渲染器异步请求 GitHub 官方 latest release 接口。只有最新稳定版本高于当前安装版本时才显示应用内更新卡片；网络或接口不可用时静默跳过，不阻塞启动。用户选择“不再提示此版本”后，版本号写入用户数据目录；仅跳过这一版本，更高版本仍会提示。外部打开链接严格限制为 `github.com/leyuwei/PDFuck/releases` 路径。
