# 2.0.37 验收与交付记录

Windows x64，2026-09-17。

## 改动

- 实验室新增“文本翻译”开关和专用 SVG 图标；首次启用时选择目标语言，激活态与“批注建议”采用同一开关样式，设置合并写入既有实验室偏好。
- 启用后，查看、编辑、批注和保存模块中的 PDF 文字选区右键菜单均可直接翻译；翻译窗口显示原文、目标语言、请求状态、结果、重试和“一键添加为高亮批注”。
- 翻译使用独立 AI requestId，不取消全文评价、自动批注等其他请求；复用既有超时和自适应恢复链路，暂时性 503 会自动重试，最终失败才显示手动重试。
- 单词选区从既有 PDF 同页文字映射中提取同栏约 32 个邻近词用于消歧；多词选区不额外发送上下文。提示词明确区分选区与参考上下文，并禁止翻译、引用或输出选区之外的内容。
- 翻译目标和新增界面文案覆盖简体中文、英语、日语、俄语、西班牙语、法语、德语、葡萄牙语、韩语和阿拉伯语。
