# 2.0.36 升级计划

## 目标

- 让 OCR 窗口的打开、缩小和关闭状态与批注/实验室模块采用一致的可见反馈。
- 将左侧“关于”入口固定为“关于 + 版本号”两行显示。
- 在标题栏加入不受界面字号设置影响的软件 Logo，并同步更新 Windows/macOS 图标资源。
- 完善 PDF 自带书签、页内链接和外部链接的解析、跳转及安全边界。
- 维持十种界面语言一致，并将新增能力纳入源码和成品发布回归。

## 实现步骤

1. 统一 OCR 工具入口的窗口状态数据与视觉样式，补充组件和真实界面测试。
2. 调整标题栏与侧栏结构；以矢量源重绘蓝底纸张小鸭 Logo，固定显示尺寸并生成 PNG/ICO。
3. 抽取 PDF.js 目标解析，支持命名/直接目标、纵向位置、URI 书签与 Link 注释；长文档等待目标页挂载后再定位。
4. 外部链接仅通过主进程安全桥交给系统，限制为 `http`、`https` 和 `mailto`。
5. 为十种语言补齐链接提示，更新 README、打包指南和发布检查。
6. 运行类型检查、单元测试、多语言/字号审计、源码 UI 回归、一键 Windows 打包及成品回归，最后记录版本、签名与 SHA-256。

## 验收标准

- OCR 缩小时入口出现与其他可缩小窗口一致的琥珀色状态；恢复和关闭状态正确。
- 左侧底部持续显示两行“关于”和 `v2.0.36`；标题栏 Logo 在四档字号、明暗主题和十种语言下保持 30px。
- 内置书签和页内 Link 可跳到正确页/位置，网页与邮件链接经安全 IPC 打开，危险协议被拒绝。
- `package-windows.ps1 2.0.36` 完整通过，并生成安装版、便携版、发布清单和可复核哈希。
