# 2.1.0 Markdown 支持

先复用 react-markdown / remark-gfm 和 Electron 的安全 Chromium 打印，不增加依赖。

- `.md` 与 PDF 共用打开、系统文件打开事件、拖入、最近文档、档案和多窗口流程；Windows 安装关联、macOS 文档类型均声明 Markdown Editor。
- Markdown 标签保留 UTF-8 源码、已保存快照与排版参数；生成的 PDF 使用独立模型及保存位置，复用阅读、编辑、批注、打印、导出模块。
- 默认左源码 / 右 PDF，拖动或键盘调整分割线；可切换源码、PDF、双栏，比例和显示偏好持久化。窄窗、RTL、双主题和四档界面字号使用原有规范。
- 源码与 PDF 使用两张编号面板，标题、提示、工具、内容和状态分区；常用语法按钮及 14 类快捷插入浮窗提供六级标题、代码语言、表格行列和语法预览，操作栏固定在底部。语法图标禁止换行，尺寸随四档字号变化。
- PDF 排版复用可拖动浮窗与滚动组件；五种 A4 模板以卡片展示（简洁、学术、商务、书刊、技术），字体族、8–24 pt 字号、1.2–2.4 行距、0–24 pt 段距及快速字号可调。不使用折叠菜单。
- 源码变动延迟自动渲染；PDF 有编辑时暂停替换，手动刷新需确认；源文件、PDF 分别保存，关闭/移动标签保留双方未保存状态。
- 不执行原始 HTML 或脚本、不加载远端图片；文档目录内本地 PNG/JPEG/GIF/WebP 与嵌入图片转为 data URL。图片/表格/代码分页保持边距，长行换行。

只运行本次新增单元与 Electron UI 冒烟测试，加类型检查、生产构建和 diff 检查。UI 覆盖文件打开、源码保存、真实 PDF 渲染/编辑/保存、五模板、分栏、十语言 × 双主题 × 四字号与窄窗。直接 electron-builder 打包 Windows，两类成品及解包 EXE 核验版本/资源/哈希，成品重跑新增测试；macOS 原生构建未在 Windows 上验收。

后续调整：用户要求顶部文件夹按钮仅保留图标，并在此后不重复已完成的测试。保持已通过的 10 项单元与 80 组 Markdown UI 结果，图标只做新定向检查；最终构建打包后仅核验交付文件及尚未执行的便携重启检查。

本轮增补：PDF 排版、刷新、保存三个按钮统一 36px；双栏标题压缩为 36px 单行，移除编号及重复说明，单栏隐藏标题并将源码保存入口移到语法工具栏。沿用五模板和现有偏好存储，兼容旧记录并分别记住每个模板的自定义字体、字号、行距、段距及当前模板。五模板对标题、引用、代码、表格、列表与分隔线使用独立区域样式，保留安全打印及现有分页规则。只新增运行本轮设置记忆和紧凑布局/区域样式检查，随后重新构建打包并更新交付校验信息。
