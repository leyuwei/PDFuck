## 根因与全局核查

这次问题不在字号数值本身，而是此前只统一了文字大小，多个文字图标仍使用固定像素盒子、固定外层列宽或不对称内边距。通过 JSX 短文字盘点及 CSS 尺寸规则核查定位同类问题。

| 位置 | 处理 |
| --- | --- |
| 欢迎页与打开弹窗的最近文件 PDF | 共用内容宽度、em 最小宽高、对称内边距和居中；两处父列表图标列改为 max-content；移除弹窗覆盖公共图标的旧尺寸/底部内边距/颜色规则 |
| 文档标签 PDF | 保留上一版已自适应的规则及原有四档/十语言回归 |
| 欢迎页主 PDF 标记、密码弹窗 PDF | 主标记相对纸张图形水平居中；密码 PDF 按字号扩展 |
| 密码与安全存储的锁图标 | 不再把“锁”的完整译文塞进固定方框，共用语言无关 SVG |
| 作者徽标 | 去除固定高度，独立姓名 span 正确显示省略号，保留完整 title、颜色圆点及 dir=auto |
| 批注/书签折叠计数、书签页码 | 居中胶囊按字号及位数扩展；外层折叠栏不再用固定最大宽度裁切 |
| 批注/书签字号步进按钮 | 列宽按内容和字号计算，按钮高度自适应 |
| 上下文菜单符号、折叠栏符号 | 文字盒子按 em 最小尺寸增长，禁止 flex 压缩 |
| 临时文件警告符号 | 固定不压缩，胶囊居中，随字号增长 |
| 页面管理的原页/当前页/旋转/删除标记 | 约束在缩略图内并允许长译文换行；底部左右徽标保留间距 |
| 当前批注提示 | 用自身高度定位到批注上方，替代固定 25px 偏移 |
| 自定义颜色“＋” | 原紧凑圆心仅 11px，替换为按圆心比例显示的 SVG 加号 |
| Aa 格式标记、B/I/U、打印/导出/另存警告等单字符图形 | 保留足够大的现有尺寸，加入四档几何标本检查 |

继续使用辅助/正文/标题三种字体角色，无新增依赖。四个预设的字号值保持 2.0.27 定义。
