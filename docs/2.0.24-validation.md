## 修复结果

- 删除编辑批注标题栏的拖动图标，只保留标题与关闭按钮；仍可拖动标题，保留标题栏避让、背景点击关闭和 Escape。
- 将颜色选择器移至正文格式工具栏右侧。色块与粗体、斜体、下划线、高亮按钮同排、同高，统一圆角；保留预设色和自定义颜色。
- 回复使用原生 details/summary 默认折叠。包括已有回复的批注，打开编辑时也默认折叠；展开后可以编辑，再收起不会清空内容或样式。
- 删除正文上方“可以补充说明”等操作提示和废弃样式。
- 斜体根因为全局 `font-synthesis: none`：Microsoft YaHei UI 等字体没有原生斜体时，浏览器被禁止生成倾斜字形。批注正文、回复和列表富文本现在允许字体合成，样式标记和 PDF 保存方式保持兼容。
