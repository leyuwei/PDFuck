# 2.0.25 升级与验证记录

日期：2026-09-08。基于 main 的 ee70bd1，版本与锁文件同步为 2.0.25。本轮未提交或推送。

## 修改与根因

- 左侧工具面板复用一个 ScrollWindow，标题固定，四个模块的全部内容在标题下滚动。批注文字工具、实验室和画板入口同属正文滚动区域，实验室持续挂载，切换模块不会中断后台任务。
- 界面统一辅助、正文、标题三种字号，标准为 12/14/18px。所有九份既有 CSS 的字号声明迁移至共享变量；批注和书签列表的 S/M/L 也引用相同变量。PDF 原文、页面文字编辑、创作文字和页码内容预览保留文档字号。
- 查看新增界面字号弹窗，提供标准、较大、最大三档设置，分别为 12/14/18、14/16/20、16/18/22px。实时预览整个界面；确认保存，取消、关闭、背景点击和 Escape 恢复保存值，重启及新窗口读取设置。支持十种语言。
- PDF 标签溢出根因是字号增大后仍沿用 25×17px 固定徽标尺寸。徽标现在使用随文字扩展的宽高和内边距，保持与文件名的间隔；真实窗口以文字 Range 检查四条边界。
- 同时修正左侧外层固定宽度裁切内层面板、工具提示固定两行截断、长译文挤占设置按钮等布局问题。按钮的通用动画只覆盖颜色、阴影和位移，避免字号切换产生三档之外的中间字号。
- 严格规范见 `docs/VI-TYPOGRAPHY.md`，实施计划见 `docs/2.0.25-plan.md`。
