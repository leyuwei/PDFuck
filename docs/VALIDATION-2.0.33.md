# 2.0.33 验收记录

环境：Windows x64，2026-09-09。用户明确要求本次按 UI 改动范围验收，跳过后续无关回归。状态：源码与 Windows 成品针对性 UI 检查均通过，安装版和便携版已生成并核验。

## 排版修改

- 模型设置：用轻量状态标签、配置名称与模型名称代替整条绿色提示，摘要到说明留 12px、说明到表单留 24px；去掉强制清零上边距的旧规则，说明恢复辅助文字颜色。长名称可换行。
- AI 实时过程：标题使用与进度卡一致的小号字；状态在右侧，窄窗口自然换行。标题下保留一条分隔，请求、思考和回复分别使用有内边距的浅底内容块；移除正文顶部和请求末尾的重复横线。
- 取消按钮位于独立尾部操作区，保留 14px 边缘留白；结果和自动批注操作按钮统一间距并支持长文案换行。共享改动覆盖智能润色、全文评价、自动批注、批注建议。
- 请求列表的项目符号跟随界面方向，正文用 `bdi` 隔离方向，避免 RTL 界面中的中英文列表圆点越界。深色主题有对应的背景和文字颜色。
- 统一实验室提示词与高级参数输入框的边框、圆角和内边距；修复隐私提示底部按钮样式未匹配滚动容器的问题。十种语言的等待说明改为跟随模型超时设置，移除过时的“最多五分钟”。
