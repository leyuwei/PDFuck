## 原因与方案

1. 样例第一页的“整体质量，”与“不诚实行为，”等文本块，PDF.js 返回的块宽含标点完整字宽，但后继文本因 PDF 的负间距提前开始，文字块边界重叠。共享 textItemsToWordBoxes 校正同行、同字号相邻文字块的尾部边界，只收紧重叠字符的边界，不缩放整行；排除跨行、脚标、旋转文字和大面积叠字。选择、光标、查询与批注共同使用校正后的几何。
2. 复用查看器的页面文字缓存及现有批注上下文机制，按批注矩形提取字符范围，而非简单按内容搜索（避免重复词串定位错位）。原文卡片显示页码、被批注文字与适量前后文，原文用 mark 区分；长内容可滚动，自动文字方向，脱离正文的便笺/图片明确显示不可提取文字。跨页批注按页码排列。创建时与编辑时共用。
3. 统一欢迎页、打开按钮/弹窗、拖入提示和原生文件过滤器的十语言通用文案；具体格式选择、另存/导出等仍保留必要的格式名称以区分行为。
4. 卡片采用现有三档字号变量和主题颜色，最小窗口仍可关闭/保存；保留编辑器焦点、拖动缩放、草稿和 AI 返回流程。

实际 UI 检查发现缩放后滚动条会改变 clientWidth，触发自动适配并使倍率反复回退。ResizeObserver 改为比较查看区域实际分配宽度，仅窗口/侧栏缩小触发适配；新增 UI 检查同时核对正常与高倍率不会因此回退。
