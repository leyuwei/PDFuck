# 3.0.38 验收与交付记录

Windows x64，2026-09-18。

## 改动

- 为文本翻译设置窗增加独立底部操作区，分隔线与按钮间保留明确内边距，不再紧贴。
- 重新整理翻译结果窗：原文使用中性卡片，译文使用主题强调色卡片，二者拥有独立标签、边框、留白和明暗主题样式；状态、错误与操作区也分别留出间距。
- PDF 内置链接与关联引文改以细下划线和轮廓提示交互；提高覆盖按钮规则的选择器权重，阻止全局 `button:hover` 将覆盖层刷成浅白色。普通、悬停、焦点及激活状态均保持完全透明，并移除原生 `title`，保留多语言 `aria-label`。
- 文档档案条目的改名与删除改为标题右侧的紧凑图标操作，删除确认仅在触发后展开到下一行；图标保留本地化 `title` 与无障碍名称。
- 本次没有新增第三方依赖或重复组件，继续复用既有弹窗、主题和多语言设施。
