# PDFuck 2.0.40 实施计划

本次复用现有 PDF.js 缩略图、十语言目录、四档字号变量、确认弹窗与最近文件写入队列，不增加依赖。

## 范围

- 水印实时预览显示当前 PDF 页面内容，并在同一页面比例上叠加水印。
- “实时预览”使用辅助字号；水印功能按钮说明在十种语言中同步精简。
- 欢迎页和打开 PDF 弹窗均可清空最近打开列表；执行前明确提示不会删除本机 PDF。
- 版本由 `2.0.39` 顺延到 `2.0.40`。

## 验证

- 新增 `test:release-2.0.40-ui`，检查真实页面预览、十语言、四档字号、两处清空入口、取消与确认行为。
- 按用户要求仅运行本次新增测试；生产构建后使用 Windows 成品复跑同一测试。
- 生成安装版、便携版、SHA-256、签名状态与精简验收记录。
